# 环境与存储说明

此文件为各模块既有相对链接提供仓库入口。本机目录规则以 /home/nanshan/workspace/docs/虚拟机目录与存储规范.md 为准，维护时修改原规范，此处不复制规则正文。

当前工作区布局如下；其他机器可使用自己的工作区根目录，并逐项核对模块配置和部署脚本。

| 内容 | 本机位置 |
| --- | --- |
| 深蓝智能汇总仓库 | /home/nanshan/workspace/projects/deepblue-intelligence |
| 各模块现有源码 | /home/nanshan/workspace/projects/<模块名> |
| 服务程序 | /home/nanshan/workspace/services/<模块名>/app |
| 服务配置与数据 | /home/nanshan/workspace/services/<模块名>/{config,data} |
| 文件日志 | /home/nanshan/workspace/services/<模块名>/logs；使用 journal 的服务按模块文档查询 |
| 开发数据与测试临时数据 | /home/nanshan/workspace/{data,tmp}/<模块名> |
| 独立工具与公开模型 | /home/nanshan/workspace/tools |
| 手动备份与旧程序 | /home/nanshan/workspace/{backups,archives}/<模块名> |

三个模块名称为 ai-gateway、ai-workbench、autotest-platform。真实配置、服务数据库、模型和依赖缓存均由部署环境独立维护。仓库中的 GitHub 源码副本不能替代包含配置、密钥和数据库的一致性备份。
