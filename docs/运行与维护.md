## 内容核对

```bash
cd /home/nanshan/workspace/projects/deepblue-intelligence
python3 scripts/verify_bundle.py
python3 scripts/verify_bundle.py --check-sources
```

第一条核对模块文件与 manifest 中的 SHA-256、文件数和额外文件；第二条同时检查本机来源工作树是否与导出内容相符。来源项目继续开发后，来源比较可能出现差异；此时先核对变化，再明确更新导出，不覆盖已有业务文件。

本次文件导入通过 git ls-files --cached --others --exclude-standard 选择来源文件，跳过已删除文件，保留有效的未提交修改与未忽略的新文件。每个模块的文件列表、SHA-256、Git 基线和脏工作树状态都记录在 source-manifest.json。不导入 .git、依赖、真实配置、运行数据或服务备份。
