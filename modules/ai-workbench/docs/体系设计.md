# 工作区AI体系与权限设计

本文件落实用户确认的方案：全工作区独立助手、小团队、资料本地保存、外部/内网模型受控调用，包含扫描OCR和项目讨论/通知。AI草案由人员确认应用，长期记忆由人员确认生效。目录规范正文仍在工作区docs，AGENTS仍是开发约束入口。

## 身份与授权

独立工作台维护自己的账号和本地项目角色。TestDock账号用60秒一次性码显式绑定；桥接HMAC绑定请求路径、时间戳、随机nonce及正文摘要，防止伪造/重放。不复制TestDock密码、不跨服务直接读业务数据库。来源端将登录用户生成的随机绑定码摘要保存，服务密钥不能自行签发绑定码；兑换后每个用户获得独立30天委托，令牌加密保存，来源端可撤销，服务签名或他人的委托不能冒用其他账号。来源账号停用/移除成员后，下一次查询实时复核即隐藏相关内容；来源不可用时闭合权限。

默认查询所有当前可见项目。TestDock项目角色从来源实时得到，工作台管理员不能覆盖；本地项目需要明确成员关系，管理员不自动拥有其他本地项目或他人的私有内容。项目只读成员可阅读和分析，编辑者维护资产/讨论，项目管理员管理成员、外发、审核与自动化；管理员管理模型/账号不等于可读他人私有会话。

所有records包含所属项目、私有/项目/工作区可见范围、来源项目依赖和来源版本。派生内容继承全部项目依赖，读取必须同时有全部来源权限。检索SQL在返回文字/排序之前限制可见记录，向量仅扫描授权行；搜索统计、通知数量、引用、任务结果与下载也复核。跨项目内容不能仅凭目标项目权限公开；用例草案应用只接受全部依据属于目标项目的草案。

## 知识与记忆

文本/代码按行，Word按段落与表格，Excel按工作表和行，PDF按页，OCR保留识别区域坐标。原文件以版本保存；已登记来源按SHA-256增量处理，修改即使旧记忆失效，来源缺失暂停引用。文件路径解析后必须在登记根内，拒绝符号链接越界、配置、密钥、依赖、备份和缓存。

FTS5使用中英切分；FastEmbed BGE-small-zh-v1.5生成本地512维向量，SQLite保存向量，分批余弦扫描与关键词RRF融合，每记录至多2个片段。窗口400字符、步长300；索引与检索不调用外部嵌入服务。语义模型不可用时明确降为关键词检索。

会话默认本人私有，最近24小时最多12条可见上下文供后续任务使用。个人偏好、项目经验与工作区通用记忆分域；记忆先pending，人工approve后进入检索，90天复审，来源版本/状态/权限改变停止作为当前知识。个人记忆共享到项目重新进入审核；私有来源需先由作者明确共享，不隐式发布。

## 消息与任务

项目讨论、回复、成员提及可检索，通知仅收件人可见，来源失权后通知和未读数同步隐藏。查看项目不等于查看他人私人对话；分享操作显式执行。站内失败订阅默认关闭，按本人来源权限拉取新失败；管理员可单独启用自动分析，仍受外发及额度控制，不自动修改/运行测试。

任务状态queued/running/completed/failed/cancelled，支持取消、手动重试；重启将已运行任务标失败，不自动重放模型调用。来源、解析、OCR与批量向量由后台处理，测试平台执行器独立。

## 模型边界

预置OpenAI及DeepSeek的OpenAI兼容协议。密钥Fernet加密，接口不回显，日志只记录受控错误。外部模型必须同时满足全部项目、每条资料及其祖先来源的外发许可；新导入的TestDock脱敏报告继承当时项目策略，其余资料默认local；可信内网由工作区管理员显式指定。模型正文只含获准脱敏片段；候选记忆不自动生效，不执行模型输出代码/命令，不改测试结果。

默认全工作区20万Token/UTC日，按保守UTF-8输入上界加输出额度预留，展示实际使用与额度占用。未知计费状态不自动重试。输出引用编号必须存在；缺少或伪造引用不发布分析结果。草案经复用TestDock 1.1 schema及来源平台当前schema验证后，仍由用户明确应用。

持久化版本2；预发布版本1初始化时只给账号绑定增加加密委托与有效期字段。TestDock新增隔离的一次性码、nonce与用户委托表，无既有业务表字段变化。升级后按迁移版本演进，禁止依赖静默改表。

来源资产按权限同步用例、套件、环境公开配置与运行概览，支持分页、手动同步和约5分钟的后台同步；同步只读，环境敏感值移除。来源内容修改产生新版本，删除则隐藏原映射及其派生内容，重新出现作为新记录处理，防止复用ID复活旧引用。
