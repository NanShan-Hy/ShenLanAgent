## 目标与范围

为小团队交付可运行的 Web 管理平台：可视化编排 Web UI 与 HTTP 接口用例，同一套件选择多个被测环境，通过手动、Cron、CI 触发，追溯运行快照、逐步结果和失败现场。Android/iOS 暂缓；分布式执行、多浏览器矩阵、录制器、性能测试、SSO留作后续独立扩展；1.2增加每日任务及结果通知。

系统管理员管理账号和项目，可访问所有项目；项目管理员管理成员、令牌和资产；测试人员编辑资产、计划并执行；只读成员浏览资产与报告。敏感变量供项目测试执行，配置接口只返回其名称。

## 技术与数据约定

Python 3.12、FastAPI、SQLite、HTTPX、Playwright、JMESPath、croniter、cryptography；精确版本以 requirements.lock 为准。前端 HTML/CSS/JavaScript 无构建依赖。SQLite 保存账号、会话、项目、成员、环境、用例、套件、执行队列、逐步结果、计划、令牌哈希和操作记录。默认 DELETE journal、短事务与一个 worker，适合当前资源，不引入 MySQL/Redis/Celery。数据库原schema=1，1.2迁移至2；升级、备份及回退见维护说明。

执行提交时加密保存环境、用例、版本快照。worker 持久领取队列，运行使用独立进程组；每个用例独立 HTTP 会话和浏览器上下文。取消、总时限及父进程退出清理子进程；worker 重启把已开始任务标记异常，不自动重放业务副作用，保留排队任务。

HTTP 支持 JSON/form/text、Headers、Query、状态/JSON/文本/响应头/耗时断言、JMESPath 提取；Web 支持导航、点击、输入、选择、勾选、按键、文本/可见/URL 断言、元素等待及截图。使用 `{{变量名}}` 引用环境与本用例提取值。Cron 五段表达式、IANA 时区、触发去重、不重叠，停机超过一分钟的过期触发跳过。CI 令牌绑定项目/创建人，可过期、撤销，失权立即生效；幂等提交防止重复运行。

环境敏感值和执行快照 Fernet 加密；密码 PBKDF2；日志按敏感字段、环境敏感值和敏感提取值脱敏。截图/Trace 可能包含业务页面和网络数据，按项目授权访问。测试人员能够通过用例使用环境凭据，角色模型面向可信团队。

## 1.1 落地完善

在既有 Web/API 与多环境范围内补齐业务接入和持续回归流程，目录与依赖位置沿用上表，不增加外部基础设施：

1. 项目资产 JSON 导出/导入：用例、套件与环境模板；敏感值不迁出，导入预览后一次性写入，错误全量回滚、名称冲突不覆盖。
2. OpenAPI 3.0/3.1 JSON 导入预览：从路径/参数/JSON 请求体生成可编辑接口用例，列出待配置变量和未支持的内容；只导入所选接口，不自动执行写入业务的请求。
3. 多环境批量执行与失败重跑：一次选择多个目标环境；支持复现原始加密快照和使用最新配置重跑，保持版本可追溯。
4. 历史查询与统计：状态、环境、触发类型、关键字、时间区间及分页，页面可查超过最近 200 条的历史。
5. 执行可靠性：限制实际请求和解压后响应体积、应用页面导航超时、修复表单类型错误，避免异常输入或目标大响应拖垮服务。
6. 使用手册与验收：覆盖导入→环境配置→多环境回归→失败修复→重跑→CI 的业务接入闭环；所有新增入口做权限/事务及真实浏览器验证，备份后部署并核对历史数据保留。

这些功能的自动化验证使用 tmp 下独立数据，人工截图与结果放 data/autotest-platform/dev。用户实际业务地址尚待提供，接入指南和演示回归先独立完成。移动端继续暂缓，开机/注销后运行状态仍按实际 linger 状态记录。

补充业务方向：用户说明类似化工品销售，并要求通用于大部分项目。平台核心保持领域无关；examples/chemical-sales.json 和独立演示目标提供商品→报价→订单示例。示例全部为虚构商品和订单，作为接入模板；不引入真实销售、支付或化学品管理功能。失败重跑同时提供“复现原快照”与“使用最新配置重跑未通过”两种选择，便于定位历史问题与验证修复。


## 1.2 每日多环境任务与外部通知

沿用现有源码、config/data/logs、开发数据及备份路径。复用Cron，提供每日/工作日09:00（Asia/Shanghai）及高级表达式，多环境原子入队、批次汇总、全部终态通知。钉钉支持内部应用机器人及存量Webhook；个人微信使用Server酱Turbo。密钥在设置页加密保存，默认不启用渠道。外部只发送结果摘要及需鉴权的报告链接，不发送响应、变量或附件。独立通知执行器使用持久队列；供应商受理与手机送达分开记录，未知发送结果人工决定重发。schema1→2显式迁移；先备份后迁移，恢复副本暂停计划/关闭渠道/取消待发。用户要求无人值守，需核实linger和用户服务实际启动状态；缺少管理员权限或真实渠道密钥时如实记录未验证事项。
