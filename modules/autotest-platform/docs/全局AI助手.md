# 全局 AI 助手（1.3）

登录 TestDock 后使用侧栏“AI 助手”或顶部快捷入口；执行报告的“AI 分析”在站内打开，并附加该报告。默认检索本人全部有权资料，也可为新会话选择当前测试项目或指定工作台知识项目。普通对话、项目分析、知识与已确认记忆可以在一个私人会话中继续，刷新或重新登录可恢复。

## 连接 AI Gateway

系统管理员打开“AI 设置”，填写 `http://127.0.0.1:8094/v1`、应用专用 Key、支持 Responses 和客户端工具的模型别名。网关对应应用应选择“可信后端传外部用户”，身份、授权版本、幂等键由 TestDock 后端生成。模型目录检查只读取列表；“发起真实测试”明确发送最多128输出Token的模型请求，费用和额度按网关配置记录。没有 Key 和模型时保持关闭，本地检索仍可使用。

只有已经在网关实际验证图片能力的别名才加入“已验证视觉模型”。目录可见不代表生成或图片能力已经验证。配置示例在 `config/ai-settings.example.json`；此文件不会自动加载。实际模型配置通过设置页加密存入 TestDock 数据库，密钥不回显、不写浏览器存储或源码。

## 本人身份和资料许可

首次使用通过真实 TestDock 登录会话的一次性票据换取短期工作台身份，不需要复制密码。原来已绑定的工作台账号直接复用；未绑定则创建无密码、非管理员身份，只继承本人实际项目角色。工作台管理员身份不会从 TestDock 管理员身份自动提升。若要关联已有工作台的私人知识，仍需本人登录原工作台，用 TestDock 账户设置中的一次性绑定码完成关联；随后站内使用无需重复登录工作台。

退出登录、停用账号、撤销AI委托或移除项目权限后，新的读取、工具调用和操作确认都会复核。撤销后须明确点击“重新连接 AI 身份”。私人会话和附件仅本人可读；跨项目派生结果继承全部来源依赖。历史来源失权或版本变化会停止沿用旧模型上下文，页面隐藏失效的消息；重建上下文不会重放旧操作。

网关虽然位于本机，实际处理者仍是外部云模型。“资料范围”中项目管理员可允许脱敏测试资产外发；工作台文档和记忆还需自身及祖先来源的外发许可。在本地检索结果中打开来源，可由有权作者/管理员修改该资料的许可。外发前保留来源位置和版本；模型项目结论需引用可核查证据。普通问候无需证据。

## 附件、截图和记忆

“添加附件”保存本人私有的加密文件。每个文件最多20MiB，每轮最多4个附件/4张视觉页；发送还需勾选本人外发同意，并满足所属项目的外发许可。报告快捷助手可选择“附加失败截图”。长文件在“详情/分段”中使用网关返回的页、工作表或行段标签；不静默截断、丢弃附件或改用其他模型。文件许可或分段改变后，旧上下文不再沿用。

AI可以创建私人记忆候选，页面提供审核按钮，确认后才进入长期记忆检索。原工作台知识、讨论、OCR和记忆审核界面继续保留。

## 操作确认

支持用例、套件、环境普通配置的新增/修改；定时任务创建、修改及启停；启动测试、多环境执行和失败重跑。模型只能提出受校验的提案，卡片展示具体参数、原配置、目标项目及未来触发时间。新增计划默认关闭；启用会按所确认的时间持续执行。敏感变量仍通过环境设置维护。

每项操作单独确认，提案10分钟有效。确认前再次检查权限、依据及项目配置；配置变化后须重新生成预览。确认与业务写入在同一数据库事务中完成，重复确认返回原结果，不重复修改或入队。跨项目依据不能直接写入单个项目，需收敛为目标项目资料。实际执行仍使用原测试队列、快照、Cron、通知和报告。

未知模型结果、断流或上下文冲突不会自动重复计费调用。查看提示后可明确“恢复为新上下文”；已经执行的操作和账本保留。任务取消不会声称上游费用必为零。清理对话会清理本人会话、附件及网关托管副本，保留测试业务与费用记录；网关请求审计按网关自己的保留规则管理。

## 运行与恢复

沿用本项目登记的源码、config/data/logs及备份位置；加密附件存于服务 `data/ai`，会话/提案/任务在 `testdock.sqlite3`。新增用户服务 `testdock-ai-worker.service`，单任务处理，MemoryMax=160MiB，日志用用户journal；每个问题最多8次模型调用，单次输出默认4096Token。模型配置默认关闭，与原测试执行器独立。

schema2升级到3须在前置备份验证后执行 `PYTHONPATH=src .venv/bin/python -m testdock.cli migrate`；部署脚本在停止接入和执行器、备份后显式升级。工作台同步升至schema3。回退时保留当前数据副本，恢复配套的前置数据库、主密钥、桥接密钥与旧程序，不直接让旧程序读schema3。

备份包括AI加密附件、配置、身份和历史。隔离恢复会关闭AI及计划/通知、撤销委托、取消待处理模型任务并拒绝待确认提案；恢复副本不会调用真实网关。真实生成必须由管理员配置有效Key后单独联调，不把本地协议通过描述为真实模型效果。
